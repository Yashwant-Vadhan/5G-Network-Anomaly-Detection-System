# Data Layer — 5G-NADS

This directory contains measurement data collected from Android 5G devices for training, testing, and evaluating the 5G Network Anomaly Detection System.

## Android Collector Data Contract (C1 Verification)

The measurement CSVs generated by the Android 5G Network Tester (`android-collector/5GNetworkTester`) follow Data Contract C1 strictly:

### Header Format
```csv
timestamp,device,manufacturer,android,operator,network_type,deployment_mode,display_override,registered,ss_rsrp,ss_rsrq,ss_sinr,csi_rsrp,csi_rsrq,csi_sinr,pci,nci,nrarfcn
```

### Observed Field Behaviours & Observations (Redmi 13 5G - `2406ERN9CI`)
* **Timestamp Format:** `dd-MM-yy HH:mm:ss` (e.g., `28-09-26 22:42:06`), captured in local device time.
* **Sampling Interval:** 3000 ms (3 seconds) between consecutive polling iterations.
* **Missing Value Tokens:** Unreported/unavailable metrics (such as CSI fields `csi_rsrp`, `csi_rsrq`, `csi_sinr`) are recorded as literal `NA`. Numerical max-int sentinels (`2147483647`) are mapped to missing in preprocessing.
* **Deployment Mode:** Reported as `UNKNOWN` on the tested Redmi 13 5G device under Airtel Non-Standalone (NSA) network conditions.
* **Cell Identifiers:** `pci` (Physical Cell ID), `nci` (NR Cell Identity, 64-bit integer e.g., `13322280247`), `nrarfcn` (NR Absolute Radio Frequency Channel Number e.g., `629952`).

## Directory Structure
* `raw/`: Raw measurement CSVs exported from Android collector devices (git-ignored, verified by `MANIFEST.sha256`).
* `processed/`: Intermediate cleaned data, engineered features, and pipeline scoring outputs (git-ignored).
* `sample/`: Small committed real-data excerpt for automated unit/integration tests and CI demo runs.
